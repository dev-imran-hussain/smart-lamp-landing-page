Luxury Dark UI Generator
This skill provides principles and structured guidance for designing premium, dark-themed user interfaces, specifically tailored for luxury e-commerce and product showcases.

When to Use
When requested to design a dark mode interface for premium products.
When creating UI/UX for luxury brands, high-end electronics, or elegant homeware.
When generating design tokens, layout structures, or CSS/React code for sophisticated, immersive product pages.
Core Design Principles
Immersive Dark Aesthetic: Use deep, rich background colors (e.g., #0B0B0C, #121212) rather than pure black to create depth.
Subtle Illumination (Glassmorphism & Glows): Incorporate soft, tinted glows to highlight key focal points. Use frosted glass effects (background blur with low opacity borders) for UI panels.
Typography: Employ elegant, high-contrast serif fonts for primary headings and clean, minimalist sans-serif for secondary text.
Minimalist Layout: Embrace negative space. Avoid clutter. Let the product photography be the hero.
Micro-Interactions: Design intuitive floating action buttons and subtle hover states (e.g., glowing borders, soft scaling).
Steps for Generation
Analyze Requirements: Understand the product, target audience, and specific branding needs.
Define Color Palette & Typography: Establish the dark background shades, primary text colors (e.g., off-white, champagne, soft gold), and font pairings.
Structure the Layout: Design the visual hierarchy. Prioritize a large central product image, layered with floating interactive elements or informational tooltips.
Draft the UI/Code: Output structured design system tokens, Tailwind classes, or React components that embody these principles.
Gotchas
Do not use high-saturation neon colors; keep accents muted and elegant (warm golds, soft silvers).
Ensure sufficient contrast for readability on dark backgrounds.
Avoid overusing glassmorphism; restrict it to floating cards, navigation, or tooltips to maintain visual hierarchy.
