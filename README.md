# AuraThinker™ — Luxury Smart Desk Lamp Landing Page

A minimal, high-aesthetic e-commerce landing page crafted for the **AuraThinker™ Sculptural Smart Desk Lamp** — an adaptive LED luminaire designed for developers, designers, and creators.

![AuraThinker Preview](https://res.cloudinary.com/dfz1dlwnz/image/upload/v1790681308/lamp_rohpz1.png)

## ✨ Features

- **Luxury Dark Glassmorphism UI:** Built with dark theme tokens (`#0B0B0C`), frosted backdrop blur, and champagne gold hover glows.
- **Dynamic 3-Variant Mode Switcher:**
  - ❄️ **Focus Mode (6500K Cool White):** High-contrast cool diode for late-night deep work and coding.
  - 📖 **Reading Mode (4000K Neutral Warm):** Glare-free balanced illumination for long study sessions.
  - 🌙 **Sleep Mode (2700K Candle Warm):** Circadian-friendly ultra-warm amber lighting to filter out blue light.
- **Interactive Lamp Crossfade:** Real-time synchronized figurine variant transitions and radiant ambient backlights.
- **Interactive Cart & Order Drawer:** Slide-over modal with live variant selector and instant order confirmation toast.
- **Comprehensive E-E-A-T & FAQ:** Verified creator reviews and interactive accordion for common user search queries.
- **100% SEO & Google Merchant Ready:**
  - Rich Schema.org JSON-LD (`Product`, `Offer`, `AggregateRating`, `Organization`, `BreadcrumbList`).
  - Open Graph & Twitter Cards for social sharing.
  - Core Web Vitals optimizations (`preload`, zero CLS via explicit image aspect ratios).
  - Search engine crawlers: `robots.txt` and `sitemap.xml` with Google Image sitemap extensions.

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript:** Ultra-fast, zero-dependency client-side execution.
- **Tailwind CSS & Custom CSS:** Responsive layouts, glassmorphic filters, and luxury radial lighting gradients.
- **Typography:** Cormorant Garamond, Cinzel & Plus Jakarta Sans.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via any static file server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```
